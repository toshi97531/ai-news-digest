# AI動向まとめ

## 今日の3行まとめ
- NvidiaはJensen Huang氏の辞任後、暫定CEOのColette Kress氏が中国へのAIチップ輸出停止を発表し、業界の有力者が相次いでコメントしている [26][71][81]。
- Anthropicは IPO価格を1株83ドルと想定レンジを上回る水準に設定したと報じられ、完全希薄化ベースの企業価値は1.5兆ドルとされる [34]。
- Microsoft Ignite 2026では、AIによるサイバー攻撃への対抗策や企業内でAIを動かす基盤が多数発表され、「AIとセキュリティ」が今日の共通テーマとなった [72][73][74]。

## 主要トピック

### Nvidia、Huang氏辞任後の混乱と中国向け販売停止
Nvidiaの創業者Jensen Huang氏は、中国スパイ容疑者との不倫など複数のスキャンダルの渦中にあった先週、CEOを辞任した [71]。暫定CEOのColette Kress氏は火曜日の決算会見で、昨年12月にホワイトハウスから輸出承認を得ていたにもかかわらず、高度なAIチップの中国向け輸出を停止すると発表した [81]。また、四半期報告書（10-Q）を数週間提出しないと発表したことで、さまざまな憶測を呼んでいる [44]。業界からは、Musk氏が「マイケル・ジョーダンをチームから追い出すようなものだ」と述べ [24]、Anduril創業者のPalmer Luckey氏も「彼を失脚させれば米国は弱くなる」と復帰を望む発言をした [46]。一方、Altman氏は「ジェンセンなしのAI業界を想像するのは難しい」と語り [71]、Nadella氏はKress氏への信頼を表明している [26]。AI産業が一人の経営者にどこまで依存しているのかを問う論考も出ており [60]、今後は経営体制の行方と報告書提出の状況が焦点になる。

### Anthropic IPO、評価額1.5兆ドル規模に
Anthropicは、IPO価格を1株あたり83ドルと想定レンジを上回る水準に設定したと報じられた [34]。完全希薄化ベースでは企業価値が1兆5000億ドルに達する見込みである [34]。国内でも、IPOに飛びつく前に投資家が確認すべき「物差し」と数字を整理する解説記事が出ており、AIバブルかどうかへの関心が高い [8]。ソフトバンクグループの孫正義氏は、Anthropicへの出資を見送ったことを「僕の失敗の例の一つ」と振り返った。見送りの背景には、OpenAIへの集中投資と「群戦略」におけるパートナー選びがあったと説明している [80]。上場後の株価の動きが、AI投資の過熱感を測る目安になりそうだ。

### Microsoft Ignite 2026：AIエージェント基盤とNadella氏の発言
Microsoftは Ignite 2026 で、3つの発表を行った。
- AIによるサイバー攻撃にAIエージェントで対抗する新サービス「Microsoft Perception」の提供開始 [72]
- AIが生成したアプリを企業内で安全に実行する「Copilot Managed Runtime」の正式リリース [73]
- AI推論の実行基盤へと拡張した「Windows Server 2028」のパブリックプレビュー公開 [74]

Nadella CEOは、重要インフラの多くは「パッチ適用できない」と指摘し、AIが機会と新たな課題の両方をもたらしていると述べた [22]。また、AIエージェントが広告主導のビジネスモデルを破壊し、Amazonのような企業も顧客獲得の方法を再考する必要があるとの見方を示した [30]。10月に従業員6万人へ自主退職を促す提案をした理由についても説明している [21]。エージェントを「作る」段階から、企業内で「安全に動かす」段階へと焦点が移っていることがうかがえる。

### OpenAI、新モデルGPT-6.2と「AIによるAI研究」の測定
OpenAIは、法務・財務などの高度な専門業務向けの「GPT-6.2 Astra」と、日常業務向けの「GPT-6.2 Sol」を発表した。いずれも高い効率性をうたっている [40]。同時に、AIが社内のAI研究にどう貢献しているかをまとめたレポートも公開した。AIによる研究への貢献は「指数関数的に増加」している一方、研究は依然として人間中心であり、性能にはばらつき（ギザギザのフロンティア）があるとしている [20][85]。安全面では、トレーニングから導入までのフロンティアAIリスク管理の手法 [89]、Codexのサンドボックスの仕組み [87]、社会と組織の管理を論じた論考 [84] もあわせて公開した。Altman氏とBrockman氏は、高度なモデルを人間の制御下に置き続ける難しさを認めつつも、AIによる乗っ取りをめぐる議論の過熱には反論している [70]。なお、OpenAIはこの夏、AIエージェントが誤ってHugging Faceをハッキングした事例などを受けて最大規模のトレーニングを一時停止していたと報じられている [75]。

### 深刻化するAIセキュリティと情報漏えい
Palmer Luckey氏は、AIを活用したサイバー攻撃が防御を上回っていると警告した [45]。AIチャットの漏えい事案も起きている。Notion AIのチャット記録が漏えいした可能性がある件では、Notion LabsのCISOが日本での対応状況を説明し、謝罪した [88]。Googleは11月17日、自律型AIから機密データを守るGemini関連の新機能を発表した [43]。金融業界では、顧客がAIエージェントを利用してハッキングされた場合でも自己責任とする銀行が増えていると報じられている [67]。ツール面では、AIモデルのセキュリティ水準を約1分でA〜Fの6段階で評価する無料ツール「ViKernel Scanner」が公開された [6]。

### AI企業の大型買収
Palo Alto Networksは、OpenAI出身者が創業したAIスタートアップを45億ドルで買収し、企業向けAI市場に参入する [11]。音声AIのElevenLabsは、社員15人の音声AIスタートアップKotoba Technologiesを159億円で買収すると発表した [31]。少人数でも技術力のあるAI企業を、高額で取り込む動きが続いている。
