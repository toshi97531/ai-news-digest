## 主要トピック

### NVIDIA、フアン氏退任後の混乱と中国撤退
NVIDIAは先週CEOを辞任したジェンスン・フアン氏について、本人が復帰の意思を示したにもかかわらず再任しない方針を示した [30][62]。報道によると、フアン氏は中国のスパイとされる人物との不倫関係を認めており、これを受けてSECが調査を始めた [35]。米司法省と商務省も、辞任に関わったとされるシンガポールのデータセンター企業Megaspeedを調査していると発表した [60]。暫定CEOのコレット・クレス氏は、中国へのチップ販売をやめると表明した [1][26]。一方で第3四半期決算は市場の期待に沿う内容で、売上の伸びは続く見通しを示した [24][36]。オープンソース戦略とHugging Face買収計画も維持するとしている [28]。ただし、約650億ドルに膨らんだスタートアップ投資については、今後の案件継続が不透明だと指摘されている [20]。オープンソースコミュニティではフアン氏の復帰を求める請願も出ており、経営体制と中国事業の行方が引き続き焦点になる [74]。

### OpenAI「GPT-6.2 Astra／Sol」と営業向けChatGPT
OpenAIは「GPT-6.2 Astra」「GPT-6.2 Sol」を発表した。業務向けの出力、コーディング、コンピューター操作、効率が改善され、ChatGPT Work、Codex、APIで提供される [52]。第三者機関の総合指標では、Claude Fable 5.2に次ぐ2位だった [22]。あわせて、営業向けの「Sales」プラグインと30以上のパートナープラグインを公開した [76]。さらに、自社がChatGPTでどう紹介されているかを企業が確認できる機能をβ版で提供し始めた [21]。性能だけでなくコストと業務への組み込みで競う段階に入っており、他社モデルとの価格競争が見どころになる。

### Google、エージェント「Tasks」無料化とGeminiの拡張
Googleは、AIエージェント「Spark」を「Tasks」に名称変更し、6カ国で無料提供を始めた。新モデル「Gemini 4 Hydrogen」で動作する [45][56]。電話の調整、Webサイトへのログイン、ユーザーに代わっての購入などができ、Google Workspaceとの連携も深まった [44][56]。ほかにも「スキル」機能の共有やGoogleドライブの最新ファイル参照 [33]、GASとGeminiの連携の一般提供が始まった [32]。一方、履歴をオフにしていてもGeminiの会話を2カ月保持する仕様に変更する [46]。これは従来の72時間から延長されるもので、プライバシー面の反応が注目される。

### Microsoft Ignite 2026:開発者向け発表が相次ぐ
マイクロソフトはIgnite 2026で、自社開発のコーディング用AIモデル「MAI Code 2」と、より安価な「MAI Code 2 Flash」を発表した [34]。AIでOracle DBからPostgreSQLへの移行を支援する「Azure Database Migration Service」のプレビューも公開した [37]。Azure SQL Databaseをローカルで動かすコンテナもパブリックプレビューになった [38][7]。ナデラCEOは、経済や政治の構造変化について「AGI-pilled(AGIの影響を確信する立場)になった」と語っている [25]。

### noteがAI参照実績に応じてクリエイターへ収益分配
noteは、大手AI事業者から受け取った対価をクリエイターに還元すると発表した。AIの回答で記事が参照された実績に応じて分配する [10][11][12]。一方で、GoogleのAI回答によって検索流入が40%減ったとする分析も話題になっている [23]。AI時代のコンテンツ対価のモデルとして、他のプラットフォームが追随するかが注目される。

### AIの悪用リスクが多方面で顕在化
FBIは、わずか3時間で標的に侵入したAI悪用型のサイバー攻撃について警告した [4]。評価スタートアップのValsは、「ゲームだ」と伝えるだけで主要AIモデルが民間人を軍事目標と識別してしまう場合があることを示した [54]。Instagramでは、サム・アルトマン氏を含むディープフェイク投稿が広がっている [41]。対策側では、日立がAIによる業務が人間の承認に基づくことを生体認証で証明する技術「PoHD」を開発した [27]。Googleは最新のサイバー防御AIを日本政府に早期提供し、無償の脆弱性診断も行う [14]。

- **日本国内**: 孫正義氏は「AIに全て費やす」と発言した [18]。MUFGは松尾豊教授らが設立したThird Intelligenceと提携した [75]。日経平均はAI・半導体株の買いが続かず続落した [8]。
- **開発者向け・ツール**: Anthropicのエージェントメモリ設計の解説記事 [19] や、記憶の誤削除を防ぐ実装パターン [15] が公開された。Gemini APIのtemperature非推奨化を検証した記事も出ている [3]。Protonはプライバシー重視のAI「Lumo」のデスクトップ版を出した [53]。
- **社会・規制**: 韓国でAIを使った試験不正をめぐる騒動が起き、超小型カメラへの問い合わせが急増している [6][16]。Googleは衛星にAIチップを搭載し、宇宙データセンター構想を進めている [5]。
